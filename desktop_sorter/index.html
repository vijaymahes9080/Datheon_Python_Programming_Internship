Safety Architecture & Collision Rules

Root & Self Protection

Target directories are checked against root drives (C:\, /), parent directories, and the sorter’s own directory. Any dangerous target is immediately aborted.

Non-Destructive Collision Resolution

If report.pdf already exists inside the Documents directory, the incoming file is systematically renamed to report_1.pdf, report_2.pdf, etc. Zero overwrites.

Dry-Run Guarantee

When executed without --confirm, the engine scans and constructs the classification plan without performing any shutil.move() operations.
