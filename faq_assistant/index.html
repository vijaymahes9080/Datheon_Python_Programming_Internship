Intent Engine & Matching Pipeline

Strict Intent Hierarchy

Evaluates inputs through an explicit pipeline: EXIT (bye, quit) → GREETING (regex match against greetings list) → FAQ_MATCH (Jaccard similarity scoring) → HELP → FALLBACK.

Jaccard Keyword Similarity

Tokens are stripped of punctuation and common English stopwords. The assistant calculates set intersection over set union against FAQ questions, triggering answers only above threshold.

Honest Clarification Fallback

When a question cannot be resolved with certainty from the verified dataset, the assistant asks a polite clarifying question instead of making up false information.
