Hangman Word Challenge

Terminal word-guessing game with ASCII gallows art, powered by a 9,894-word Google English dataset.

  • Random word selection from validated dataset
  • 7-stage ASCII gallows with progressive drawing
  • Six-error limit with duplicate-guess protection
  • Victory/defeat screens and replay support

Desktop File Sorter

Safe, extension-based file organizer with dry-run preview, collision protection, and explicit confirmation before any file is moved.

  • 9 categories: Documents, Images, Videos, Audio, Archives…
  • Dry-run preview mode — moves nothing
  • Filename collision renamed, never silently overwritten
  • Unsafe targets (roots, script dirs) rejected

FAQ Conversation Assistant

Rule-based chatbot grounded in a real FAQ JSON dataset. Uses Jaccard-similarity keyword matching for intent classification.

  • Answers from the actual dataset — no fabricated facts
  • Intent pipeline: exit → greeting → FAQ match → help → fallback
  • Input normalisation: casing, whitespace, stopwords
  • Graceful handling of missing/malformed JSON

Technology

Architecture & Technology Stack

All applications use Python's standard library exclusively. No paid services, no live network dependencies for core functionality.

Application Entry Point Key Modules External Data
Hangman Word Challenge word_challenge/game.py random, pathlib, sys Google 10k English (TXT, 75 KB)
Portfolio Market Journal market_journal/tracker.py csv, json, datetime, pathlib S&P 500 Constituents (CSV, 503 rows)
Desktop File Sorter desktop_sorter/sorter.py shutil, pathlib, argparse, logging None — filesystem only
FAQ Conversation Assistant faq_assistant/assistant.py json, re, pathlib, sys FAQ JSON (3 entries, 5 greetings)

Running the Applications

Terminal — from project root 
$ python word_challenge/game.py
# Start the Hangman game

$ python market_journal/tracker.py
# Start the Portfolio Tracker

$ python desktop_sorter/sorter.py --target ~/Downloads --dry-run
# Preview file organisation (no files moved)

$ python desktop_sorter/sorter.py --target ~/Downloads --confirm
# Execute sort with confirmation prompt

$ python faq_assistant/assistant.py
# Start the FAQ chatbot

Running Tests

unittest — from project root 
$ python -m unittest discover word_challenge/tests -v
$ python -m unittest discover market_journal/tests -v
$ python -m unittest discover desktop_sorter/tests -v
$ python -m unittest discover faq_assistant/tests -v
