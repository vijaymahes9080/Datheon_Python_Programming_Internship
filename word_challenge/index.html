Terminal Execution Guide

The game runs natively in PowerShell, Command Prompt, or Unix bash with zero external dependencies.

# 1. Navigate to the project directory

cd d:\intership\python\vj\word_challenge

# 2. Launch the terminal game

python game.py

# 3. Run full automated unit test suite

python -m unittest tests/test_game.py -v

Architectural Highlights

Word Ingestion & Fallback

Loads words from resources/words.txt (Google 10,000 English word list). Validates length between 4 and 12 characters, strips whitespace, and automatically falls back to an embedded 50-word bank if the file is missing or corrupted.

Finite State ASCII Gallows

Constructed with 7 explicit visual stages (index 0 to 6). Progresses cleanly through no mistakes, head, torso, left arm, right arm, left leg, and final loss state (full figure).

Defensive Input Sanitizer

Guards against multi-character inputs, digits, special symbols, and already-guessed letters. Redundant guesses trigger an informational prompt without penalizing player attempt counts.

Validation & Test Coverage

Unit testing implemented using Python's built-in unittest module covering 100% of core gameplay rules.
